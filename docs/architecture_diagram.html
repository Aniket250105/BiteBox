2. API Gateway Tier

Express 5.x Server

🔒 Security & CORS Lock
Origin validation, JWT authentication, sliding-window rate limiting (30 req/min per IP).
Express 5 + JWT
🛡️ Zero-Trust Input Sanitizer
Client totals ignored; prices recalculated strictly server-side. XSS & SQLi protection.
Parameter Binding
🌐 Tunnel & Dev Proxy
Cloudflare Tunnel edge proxy routing HTTPS traffic directly to local Vite & API servers.
Cloudflare Edge
▼ Service Invocations & Cache Cascades ▼

3. Business Logic Tier

Domain Services

📍 Spatial Geolocation Service
Overpass API queries, Haversine 3km radius filtering, multi-tier fallback (Cache → Snapshot → Seed).
Haversine Filter
🏷️ Coupon & Pricing Engine
Rule-based discount validation (WELCOME50, FESTIVE20, BITE100) and exact 5% GST rounding arithmetic.
Quote Engine
🔄 Order Lifecycle FSM
Finite-state machine enforcing strict transitions: Placed → Confirmed → Cooking → Picked Up → Delivered.
State Machine
▼ Synchronous ACID Transactions (WAL Mode) ▼

4. Persistence Tier

SQLite 3 Relational DB

💾 Relational Data Schema
11 relational tables with foreign keys and cascade rules (customers, orders, items, payments, history).
better-sqlite3
⚡ High-Speed Geo Cache
Sub-3ms spatial caching for OSM nodes and bounding boxes with preserved cache tables across seeds.
WAL Mode
🛡️ Atomic Stock Isolation
Serialized transactions guaranteeing zero overselling on concurrent checkouts with rollback on fail.
ACID Guarantees
